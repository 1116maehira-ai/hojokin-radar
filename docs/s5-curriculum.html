🔌 A. Supabase接続の完成（止まっている人）
1
GitHub Pagesのサイトを開いてコンソールを確認
右クリック → 検証 → Consoleタブ。「Supabase接続OK」か「データ取得エラー」かを確認
2
ClaudeにHTMLとキー情報を渡して接続コードを追加してもらう
「このHTMLにSupabaseのProject URL: ○○、APIキー: ○○を使って接続コードを追加して」と伝える
3
SQLエディターで「テーブルが存在するか」を確認
Supabase → Table Editor でpage_contentsテーブルがあるか確認。なければフェーズ2のSQL実行からやり直し
4
新しいindex.htmlをGitHubにアップ（上書き）
ファイル名を必ず「index.html」にしてアップ。(1)(2)などのカッコは消すこと
📝 B. CMS管理画面を使ってみる（全員）
1
CMS管理画面（cms.html）をGitHubにアップ
Claudeに「CMS管理画面のhtmlを作って」と依頼。受け取ったファイルをGitHubのJSフォルダ等の正しい場所にアップ
2
管理画面にブラウザでアクセス
https://ユーザー名.github.io/リポジトリ名/cms.html にアクセス
3
採用サイトのキャッチコピーを1文字変えて「保存」を押す
「私たちはこの街を鉄で支える」など任意の文字を変更して更新ボタンを押す
4
採用サイトを開いて変更が反映されているか確認
GitHub Pagesのサイトをリロード → 変えた文字が表示されていれば成功！
🖼️ C. サイトの整え（午後）
1
各自のサイトでズレている箇所・画像が映らない箇所をリストアップ
前回から引き続き「ページがずれている」「画像がぼけている/表示されない」個所を洗い出す
2
画像ファイル名の不一致を修正
HTMLのsrc属性に書かれているファイル名と、GitHubにアップした実際のファイル名が一致しているか確認。日本語ファイル名は英数字に変更

自分のセクションの写真を新しい写真に差し替えてみる
スマホで撮った写真をGitHubにアップ → HTMLのsrc属性を書き換え → CMSか直接GitHubで更新
