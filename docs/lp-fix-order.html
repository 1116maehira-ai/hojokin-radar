01法令リスク ─ 今日中に

「補助金申請代行」の表記が2箇所。これは社会保険労務士の独占業務にあたります。

なぜ直すのか

AI研修と組み合わせる助成金は人材開発支援助成金＝厚生労働省のものです。この申請書類の作成・提出は、社会保険労務士の独占業務（社会保険労務士法27条／違反すると1年以下の懲役または100万円以下の罰金）。

実際にやっていなくても、「代行します」と表示すること自体が問題になり得ます。「嘘つく・誤魔化す・隠す」を掲げている会社が、ここで足を掬われるのがいちばんもったいない。

やることは変わりません。TENOHIRAは「研修の提供者」に徹し、書類を書くのは御社。TENOHIRAは書き方をお伝えする──この立ち位置に言い換えるだけです。

04ここは、絶対に触らないでください

このLPの強いところ。直すついでに薄めてしまうと、もったいない。

残すもの理由
CASE 4件（実績）アイムユニバース／宜野湾電設／IMI／琉球スフィア。具体名・具体の言葉・動画リンクまである実績は、沖縄の同業でほぼ持っていません。ここがこのLPの心臓です
「沖縄を拠点に15年、1,000本以上」手紙にも架電スクリプトにも転用しています。数字が効いています
「発注前に、企画構成を無料でご提案」ヒアリング商談へのハードルを下げる最強の材料。手紙の締めにも使っています
「8万円〜500万円前後まで」500万の実績があると言えている。305万のフルパッケージが射程内だと示す根拠
「最短3週間で納品」式典に間に合わないと諦めている会社を拾えます
MESSAGEの温度文法は直しても、言い切りの熱は削らないでください。整えすぎると別人の文章になります
