Block C — 画像CMS対応（13:00〜14:30）今日の山場
C

画像をCMSから更新できるようにする

90分
仕組みの解説：今は画像パスがindex.htmlに書かれている。これを「SupabaseのDBに画像URLを保存して、LPがそのURLを読み込む」に変える。CMSで画像URLを書き換えるだけでLPの画像が変わるようになる。

まず1枚だけ試す。Section-01の技術者の写真（一番上のメイン画像）から始める。成功したら他の画像も同じやり方で追加できる。
1
Supabaseにデータを追加する（SQL実行）
Supabaseのダッシュボードを開く。左メニューの「SQL Editor」をクリック。
SQL — このままコピーして SQL Editor に貼り付けて実行
-- Section-01の技術者写真のURLをCMSで管理できるように追加
INSERT INTO site_content (content_key, value, section, label)
VALUES
  ('img_s01_technician', '', 'section-01', 'Section01：技術者の写真URL'),
  ('img_s01_office',     '', 'section-01', 'Section01：オフィス社員の写真URL');
「Success. 2 rows affected」と表示されたらOK。
⚠️ valueは空文字「''」のままでいい。空のときはLPが元の画像を表示する（後で確認）。
2
index.htmlにコードを追加する（Claudeに依頼）
GitHubからindex.htmlのRawをコピーして、Claudeに以下を依頼する。
Claudeへのプロンプト

採用サイトのindex.htmlを修正してほしいです。 以下が現在の全文です。 [index.htmlをここに貼る] Supabaseから取得したデータで、以下の2つの画像のsrcを書き換えるコードを追加してください。 ・content_key = "img_s01_technician" の値を src="./assets/section-01/photos/technician-extended.webp" の img タグに反映 （valueが空文字のときは元のsrcのままにしてください） ・content_key = "img_s01_office" の値を src="./assets/section-01/photos/office-staff-extended.webp" の img タグに反映 （valueが空文字のときは元のsrcのままにしてください） Supabaseのデータ取得処理はもうindex.htmlにあります（mapという変数でkey→valueが入っています）。 そのmapを使って、データ取得後に画像srcを上書きするコードを追加してください。 修正後のindex.htmlを丸ごと出力してください。
